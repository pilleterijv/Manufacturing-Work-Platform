# Manufacturing-Work-Platform

A web application for manufacturing employees to:

- Execute standard work
- Answer Yes/No verification questions
- Capture photographic evidence
- Perform time studies
- Review time-study statistics
- Export data to Excel
- Store historical records in a database
- Access troubleshooting guides

Future modules may include:
- Centerlines
- Training
- Audits
- Changeovers
- Problem solving
- 2D / 4D / 8D
- Equipment history
