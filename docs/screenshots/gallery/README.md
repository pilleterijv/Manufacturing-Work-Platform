# Floorwork screenshot walkthrough

27 actual browser views captured from a local production build using synthetic data. No live workplace records or credentials are shown.

- Open **Floorwork-screen-walkthrough.pdf** for a 28-page overview.
- Download **Floorwork-screenshots.zip**, extract it, and open **index.html** for every full-page screen with navigation and explanations.
- **Floorwork-all-sections.png** is the contact sheet.
- The individual numbered PNGs contain the full forms, reports and histories, including content below the initial viewport.

The 2D / 4D / 8D implementation follows the supplied workbook. The private Microsoft Forms editing links were not readable; exact question and layout matching is pending accessible form references. Live provider video playback and Microsoft Forms/Power Automate/email/Entra integrations are not represented as configured.

Reproduce against a local test app with `npm run screenshots`. This creates synthetic fixture accounts/records and removes them after capture. The numbered screenshots and static HTML are generated by that script. The PDF summarizes the viewport captures; the PNGs retain the full pages. Screenshots are excluded from the source ZIP to keep the application download small.
